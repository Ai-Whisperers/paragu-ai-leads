## 2. Standard Operating Procedures

### SOP 1: Messaging Outreach

```
PURPOSE: Initial contact with new leads
WHEN: Daily at 9am (Paraguay time)
TOOLS: Messaging Business

STEPS:
1. Open lead list
2. Select 20-30 leads for today
3. Personalize message with business name
4. Send message
5. Log in tracker
6. Repeat until done
7. Check responses at 12pm and 6pm

RULES:
- Don't send more than 50 messages/day
- Wait 24h between messages to same lead
- Never spam - 3 message max per lead
- Use templates but personalize
```

### SOP 2: Phone Outreach

```
PURPOSE: Follow up on non-responsive Messaging leads
WHEN: Days 3, 7, 14 after initial message
TOOLS: Phone + Lead tracker

STEPS:
1. Pull list of leads with no Messaging response
2. Dial each number
3. Follow script (see LEAD_MANAGEMENT.md)
4. Log outcome in tracker
5. Move to appropriate status

RULES:
- Call between 9am-6pm only
- Maximum 20 calls/day
- Leave voicemail if no answer
- Don't call same lead more than 3 times
```

### SOP 3: Website Generation

```
PURPOSE: Create website from collected info
WHEN: After intake form completed
TOOLS: Template system + Hosting

STEPS:
1. Review completed intake form
2. Select template matching business category
3. Input:
   - Business name + tagline
   - Services + prices
   - Contact info (phone, Messaging, address)
   - Team/stylist profiles (if provided)
   - Photos (from intake or stock)
4. Generate preview
5. Review for errors
6. Send to lead for approval

ERROR CHECK:
- Check phone numbers format
- Verify address is readable
- Ensure all images load
- Test Messaging link works
```

### SOP 4: Website Launch

```
PURPOSE: Go live with approved website
WHEN: After lead approval
TOOLS: Domain registrar + Hosting provider

STEPS:
1. Generate domain name (if needed)
2. Purchase domain ($15/yr)
3. Configure DNS
4. Upload website to hosting
5. Test all pages load
6. Test contact forms work
7. Submit to Google Search Console
8. Send welcome package to lead

CHECKLIST:
- [ ] Homepage loads
- [ ] All pages accessible
- [ ] Images display
- [ ] Forms submit
- [ ] Messaging link works
- [ ] Mobile responsive
```

- [ ] Contact form submits successfully
- [ ] Messaging button links correctly

|--------|--------|

| Response time (email) | < 24 hours |
| Website delivery time | < 7 days from intake |
| Revisions included | 2 free, then $25 each |

- All text in Spanish (Paraguayan Spanish)
- Professional tone, friendly
- Prices in Guarani (PYG) with USD equivalent optional

## 8. Problem Solving

### Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| Lead doesn't respond | Phone call after 3 days |
| Lead wants more features | Offer PRO tier upgrade |
| Lead needs changes | 2 free revisions, then $25 |
| Website doesn't load | Check hosting, contact support |
| Domain issues | Verify DNS, wait 24h |
| Messaging link broken | Test link format: tel:+595... |
| Images not showing | Check file size < 1MB, correct format |
| Lead wants to cancel | Understand why, offer solutions |

### Escalation Path
1. Issue occurs
2. Try standard solution
3. If no resolution in 24h, escalate
4. Document issue for future reference

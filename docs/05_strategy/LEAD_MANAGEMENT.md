## 2. Contact Strategy

### Channel Mix
| Channel | Use Case | Priority |
|---------|----------|----------|
| **WhatsApp** | Primary contact - Paraguay market | HIGH |
| **Phone Call** | Follow-up on non-responders | MEDIUM |
| **Instagram DM** | Secondary if no WhatsApp | LOW |
| **SMS** | Last resort fallback | LOW |

### Contact Sequence
```
Day 0: WhatsApp message (first attempt)
Day 3: Phone call (if no response)
Day 7: WhatsApp message (second attempt)
Day 14: Instagram DM (if available)
Day 21: Final attempt (phone)
Day 30: Mark as "No Response" - move to nurture
```

## 3. WhatsApp Outreach

### Initial Message Template (Spanish)
```
Hola [Name]! 👋

Soy [Your Name] de Paragu-AI. Vemos que tienes [Business Type] en [City] y nos encantaría ayudarte a conseguir más clientes.

Creamos sitios web PROFESIONALES y TOTALMENTE BONOS para negocios de belleza y bienestar en Paraguay.

💡¿Quieres saber cómo funciona? Es很简单 - te ayudamos a tener una presencia online sin costo.

¿Tienes 2 minutos para darte más información?

Saludos!
[Your Name]
```

### Follow-up Messages
```
Option A (After no response):
"Hola [Name]! Solo pasaba a recordarte sobre lo de la página web gratuita. ¿Te interesa?"

Option B (After interest):
"Perfecto! Para empezar, necesitamos:
1. Nombre de tu negocio
2. Qué servicios ofreces
3. Tus horarios
4. Algunas fotos de tu trabajo

¿Me los envías por aquí?"
```

### Message Rules
- Send between 9am-7pm (Paraguay time)
- Wait 24h between messages
- Never send more than 3 messages per lead
- Personalize with business name/category

## 4. Outreach Script (Phone)

### Opening
```
"Hola, soy [Name] de Paragu-AI. ¿Hablo con [Business Name]?"
```

### Value Proposition
```
"We help beauty and wellness businesses in Paraguay get more customers through free professional websites. I wanted to see if you'd be interested in learning more."
```

### Common Objections
| Objection | Response |
|-----------|----------|
| "I already have a website" | "Great! Can I take a quick look and see if there's anything we could improve?" |
| "I'm not interested" | "No problem at all. Just to understand - is it the timing or is it not something you need right now?" |
| "I don't have time" | "I understand. How about I send you a quick WhatsApp with info, and you can review it whenever convenient?" |
| "How much does it cost?" | "We have a FREE tier for basic websites. If you want premium features, it's very affordable. Can I tell you more?" |

### Closing (Interested)
```
"Perfecto! What's your WhatsApp number so I can send you the intake form?"
```

## 5. Lead Tracking System

### Fields to Capture
| Field | Source | Notes |
|-------|--------|-------|
| Business Name | Data | From phone/website |
| Contact Name | Conversation | Ask directly |
| Phone | Data + verified | Verify during call |
| WhatsApp | Conversation | Confirm active |
| Category | Data | From category |
| City | Data | From city field |
| Address | Data | Optional |
| Current Online | Conversation | Website? Instagram? |
| Interest Level | After contact | Hot/Warm/Cold |
| Contact Date | Auto | First contact |
| Status | Auto | New/Contacted/Interested/Converted/No Response |

### Status Flow
```
NEW → CONTACTED → INTERRESPONDED → CONVERTED
                → NO RESPONSE → NURTURE
                → NOT INTERESTED → CLOSED
```

## 6. Conversion Process

### Stage 1: Interest Captured
- [ ] Lead responded to outreach
- [ ] Confirmed business name
- [ ] Agreed to learn more

### Stage 2: Information Collected
- [ ] Sent intake form
- [ ] Received completed form
- [ ] Confirmed services + pricing
- [ ] Received photos (or scheduled to take)

### Stage 3: Website Built
- [ ] Generated from template
- [ ] Sent preview link
- [ ] Requested feedback
- [ ] Made revisions (if any)

### Stage 4: Launch
- [ ] Lead approved final version
- [ ] Website went live
- [ ] Set up WhatsApp integration
- [ ] Sent login details

### Stage 5: Follow-up
- [ ] Check in after 1 week
- [ ] Check in after 1 month
- [ ] Offer upsell opportunities

## 11. COMPETITIVE RESPONSE DEALS

### 11.1 If Someone Offers Free Website
- Match: FREE tier + extra features
- Differentiate: Better design, booking integration, support
- Emphasize: "Free is free, but we give more"

### 11.2 If Someone Undercuts Prices
- Don't compete on price
- Compete on value/features
- Add more included features
- Better support/ service

### 11.3 If Competitor Has Better Features
- Match feature + add more
- "We have that PLUS..."
- Focus on what makes us unique
- Better customer service
